## Content Calendar Structure

### Daily Posting Schedule
| Time | Platform | Content Type | Purpose |
|------|----------|-------------|---------|
| 9:00 AM | Facebook Page | Educational carousel | Value-driven awareness |
| 12:00 PM | Facebook Group | Discussion prompt | Community engagement |
| 6:00 PM | Facebook Group | Case study / tip | Conversion-oriented |
| 8:00 PM | Facebook Page | Testimonial / result | Social proof |

### Weekly Theme Rotation
| Day | Theme | Content Focus |
|-----|-------|--------------|
| Monday | Mindset & Career | VA journey, salary growth, success stories |
| Tuesday | PPC Education | Campaign types, metrics, bidding |
| Wednesday | Tools & Tech | Software, automation, workflow |
| Thursday | Client Management | Communication, reporting, scaling |
| Friday | Community Spotlight | Student wins, Q&A, discussions |
| Saturday | Deep Dive | Long-form case study or tutorial |
| Sunday | Rest / Prep | Behind-the-scenes, upcoming content |
